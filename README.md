# КЛЬОВ

Mobile-first MVP для планування риболовлі. Застосунок оцінює, наскільки поточні погодні умови підходять обраному виду риби, і пояснює результат.

> Індекс умов — не гарантія улову. Реальний результат залежить від водойми, рибальського тиску, снасті й техніки.

## Можливості

- пошук населеного пункту з автодоповненням;
- GPS або ручне введення координат із Compass;
- профілі щуки, судака, окуня, жереха, сома, коропа, ляща та карася;
- прогноз на сьогодні, завтра й післязавтра з погодинними температурою, вітром, поривами, тиском, хмарністю та опадами;
- ручне уточнення типу водойми, течії, прозорості, температури води й укриттів;
- пояснюваний індекс 0–100, рівень упевненості й короткі тактичні поради;
- збереження останньої локації, виду риби та умов водойми лише в браузері користувача.

## Запуск

Потрібен Node.js `>=22.13.0`.

```bash
npm install
npm run dev
```

Локальна адреса за замовчуванням: `http://localhost:3000`.

## Перевірка

```bash
npm run lint
npm run build
```

## Дані та приватність

Погода й геокодування надходять з [Open-Meteo](https://open-meteo.com/). Координати та параметри водойми зберігаються у `localStorage` на поточному пристрої й не надсилаються на власний сервер застосунку. Після відновлення сесії погода завантажується заново — старий прогноз не використовується як актуальний.

## Структура

- `app/page.tsx` — інтерфейс, локація, API-запити та локальне збереження;
- `app/fish-model.ts` — видові профілі й розрахунок індексу;
- `app/globals.css` — адаптивний дизайн;
- `app/layout.tsx` — метадані й базовий layout;
- стандартний Next.js App Router — локальний і production runtime.

## Розгортання

Codex Sites, D1 і Drizzle не використовуються. Проєкт працює на стандартному Next.js і розгортається у Vercel з гілки `main`.
